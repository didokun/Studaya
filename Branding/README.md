# Studaya artwork

Master: `Studaya-artwork.png`, generated with the built-in imagegen tool.

Prompt direction: one sculptural graduation cap whose flowing ribbon base becomes a planner sheet with three embossed schedule slots; pearlescent lavender, satin ceramic/glass, ivory highlights, restrained peach reflections, rich violet background. No lettering, book, checkmark badge or separate stock icons.

Run `scripts/generate-brand-icon.swift` using the command in its header to produce the opaque 1024 × 1024 app icon and matching in-app logo. SwiftUI applies rounded corners to the in-app image; iOS masks the app icon.
